# 🎮 Juego Multijugador con Salas y Chat

Un juego 2D multijugador en tiempo real hecho con **JavaScript, Node.js y Socket.io**.

Los jugadores pueden:
- 👤 Mover su personaje
- 🗺 Cambiar de sala
- 💬 Chatear en tiempo real
- 🚫 Colisionar con objetos del mapa
- 💾 Guardar su progreso automáticamente

---

## 🚀 Tecnologías utilizadas

- Node.js
- Express
- Socket.io
- HTML5
- CSS
- JavaScript

---

## 🕹 Características

### 🎮 Movimiento
El personaje se mueve con las flechas del teclado.

### 💬 Chat en tiempo real
Los jugadores pueden enviarse mensajes dentro de la sala.

### 🗺 Sistema de salas
El juego incluye:
- Plaza
- Bosque
- Castillo
- Cafetería ☕

Cada sala tiene colisiones propias.

### 🧱 Sistema de colisiones
- Paredes invisibles
- Objetos bloqueados
